# Employee Management System (Backend)

## Overview
This is a **backend application** built using **Java Spring Boot** to manage employee data. It provides **CRUD operations** for employee records, including create, read, update, and delete functionalities.

## Purpose
The project demonstrates how to handle **data management** efficiently using Spring Boot and JPA. It is designed for learning backend development concepts, RESTful API design, and database integration.

## Features
- Create, read, update, and delete employee records
- Track employee attendance
- Calculate salary based on attendance
  
## Tech Stack
- Java, Spring Boot, Spring Data JPA
- MySQL
- Maven for build management
- Git for version control
